# 🌍 Air Quality Classification using Machine Learning

## 📌 Project Overview
This project focuses on classifying air pollution levels using environmental data and machine learning techniques. The goal is to analyze air quality indicators and predict pollution levels based on multiple features.

---

## 🎯 Objective
To build and evaluate machine learning models that classify air quality levels using environmental factors such as PM2.5, PM10, NO2, and other related variables.

---

## 📊 Dataset Description
The dataset contains air pollution measurements from multiple cities and countries, including:
- PM2.5 (μg/m3)
- PM10 (μg/m3)
- NO2 (μg/m3)
- Temporal coverage percentages
- Year and location data

---

## ⚙️ Methodology
The project follows these steps:
1. Data Cleaning and Preprocessing  
2. Handling Missing Values  
3. Feature Engineering (Air Quality Level Classification)  
4. Data Visualization  
5. Model Training and Testing  
6. Model Evaluation  

---

## 🤖 Machine Learning Models Used
- Logistic Regression  
- Decision Tree Classifier  
- Random Forest Classifier  
- Support Vector Machine (SVM)  
- Naive Bayes  

---

## 🏆 Best Model Performance
The Random Forest Classifier achieved the highest accuracy among all tested models and was selected as the best-performing model.

---

## 📈 Evaluation Metrics
The models were evaluated using:
- Accuracy  
- Precision  
- Recall  
- F1-score  
- Confusion Matrix  

---

## 🧰 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  
- Seaborn  

---

## 💡 Key Insight
Machine learning models, especially ensemble methods like Random Forest, are highly effective in classifying air quality levels based on environmental data.
